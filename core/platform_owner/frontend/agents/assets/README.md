# App logos

Each known app's own mark, shown only to say which app is being connected. Each is the
official icon scaled to 88 px, twice the 44 px it is drawn at.

- `chatgpt.png`: OpenAI's ChatGPT/Codex editor extension icon, `blossom.dark.png`
  (open-vsx.org/extension/openai/chatgpt).
- `codex.png`: the Codex app logo, `webview/assets/codex-app-ga-logo-*.png` in the same
  extension package. A cloud, not a square: it is drawn whole, with no corners of its own.
- `claude.png`: claude.ai's touch icon (claude.ai/apple-touch-icon.png).
- `hermes-light.png`, `hermes-dark.png`: Hermes Agent's app icon, `Square150x150Logo(-dark).png`
  in the NousResearch/hermes-agent repository (apps/desktop/assets/appx); dark in the dark theme.
