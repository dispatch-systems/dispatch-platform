# Every route collection registers: its method and path, who may call it, the
# database access its work runs under, and whether it wakes the scheduler.
# Each changes with this file, so a reviewer sees who can reach what. <scheduling> is the
# permissions the features' keepers set schedules under, <collecting> those they collect
# under, and <reading> those of the sections that show a live reader: the build's features
# decide them.
GET /api/dsp/collectors Dsp(<scheduling>) Read
GET /api/dsp/connections Dsp("connections.manage") Read
GET /api/dsp/connections/{provider} Dsp("connections.manage") Async
GET /api/dsp/connections/{provider}/screenshot Dsp("connections.manage") Async
GET /api/dsp/live-readers/{reader} Dsp(<reading>) Read
GET /api/platform/jobs PlatformOwner Read
